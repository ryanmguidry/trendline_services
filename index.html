Product Recommedations!!


The ASUS ROG Z13 is an exceptionally powerful tablet that is primarily designed for gaming. However, its performance extends far beyond gaming, making it an excellent workstation for demanding professional applications.

On my current ROG Z13, I regularly run several resource-intensive programs simultaneously, including:
  • VirtualBox running a Windows 10 virtual machine for Allen-Bradley development software
  • AutoCAD
  • Autodesk Fusion
  • Thinkorswim
  • Bambu Studio
  • Lively Wallpaper
Even with this demanding workload, the ROG Z13 handles these applications efficiently, demonstrating that it is capable of much more than gaming alone.
